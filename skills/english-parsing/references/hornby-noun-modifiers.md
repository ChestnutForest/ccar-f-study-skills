## §3.81 名詞の形容詞的用法（名詞＋名詞）

### 規則

名詞が、他の名詞の**修飾語**として用いられる。この「名詞＋名詞」の語群は**自由に作られる**（つまり、決まった一覧があるわけではなく、必要に応じて新造できる）。

### 表記のゆれ

書き方は3通りあり、**厳密な規則はない**。

| 表記 | 例 |
|---|---|
| 2語に分ける | `the weather forecast`（天気予報） |
| ハイフンで結ぶ | `pay-day`（給料日） |
| 1語にする | `airmail`（航空便） |

同一の語でも揺れる：`head master` / `head-master` / `headmaster`（校長先生）。

### 強勢の位置

- 通常、**第1強勢は後ろの名詞**に置かれる（head **master**）
- ただし**対比を明示する場合**は、修飾語側に第1強勢が移る
  - `This garden has a **brick** wall; that garden has a **stone** wall.`（この庭は煉瓦塀、あの庭は石の塀）
- **2番目の名詞が動作主の -er で終わる場合**は、**最初の名詞に第1強勢**：`a **language** teacher`（語学教師）、`a **song**-writer`（作詞家）、`a **window**-cleaner`（窓ガラス掃除人）、`**theatre**-goers`（観劇家）、`a **pipe**-smoker`（パイプタバコをのむ人）

### 例

`the parish church`（教区教会）／`the evening paper`（夕刊）／`garden flowers`（栽培種の花）／`a flower garden`（花園）／`your family tree`（系図）／`a school dictionary`（学習用辞典）／`a silver spoon`（銀のさじ）／`a return ticket`（往復切符）／`the murder weapon`（凶器）／`birth-control`（産児制限）／`rainfall`（降雨量）

### 技術英語での実例（学習ログより）

`tool calls`（ツール呼び出し）／`shell commands`（シェルコマンド）／`project rules`（プロジェクト規則）／`event schemas`（イベントスキーマ）／`use cases`（ユースケース）／`environment variable`（環境変数）／`permission rules`（権限ルール）／`version control`（バージョン管理）／`context window`（コンテキストウィンドウ）

## §3.82 修飾語側は「単数形」が原則（ただし例外あり）

### 規則（最重要・TOEIC 頻出）

可算名詞が形容詞的修飾語に用いられるとき、**意味が複数であっても、形は単数形**を用いる。

| 正 | 誤 |
|---|---|
| `a seed catalogue`（種子のカタログ） | × a seeds catalogue |
| `a street plan`（町の見取図） | × a streets plan |
| `tooth decay`（歯の腐朽） | × teeth decay |
| `an armchair`（肘掛け椅子） | × armschair |

`lady doctors`（女医）／`boy friends` / `girl friends`（ボーイ/ガールフレンド）も同型。

### ⚠️ 例外1：man / woman は複数形になる

**man, woman だけは例外**で、中心の名詞が複数になると修飾語も複数化する。

- `a man teacher` → `men teachers`（男の先生）
- `a woman teacher` → `women teachers`（女の先生）

### ⚠️ 例外2：本来複数形の名詞も、しばしば単数形になる

`trousers`（ズボン）のように通常は複数形で使う名詞でも、修飾語になると単数化することが多い。

`trouser buttons` / `trouser pockets`（ズボンのボタン/ポケット）／`pyjama cords`（パジャマのひも）／`a billiard table`（玉突き台）

### ⚠️ 例外3：複数形が保たれる場合もある

**「原則は単数」を機械的に適用すると誤る。** 次のように複数形のまま用いる例がある。

| 例 | 備考 |
|---|---|
| `a sports car`（スポーツカー） | |
| `games master` / `games mistress`（競技担当の先生） | |
| `a savings bank`（貯蓄銀行） | 複数の貯蓄を扱う→集合的意味 |
| `the arms race`（軍備競争） | arms（＝armaments）は常に複数形 |

**技術英語での実例**：`the commands reference`（コマンドリファレンス）——複数のコマンドを網羅した参照資料、という集合的意味のため複数形が保たれる。`a savings bank` と同型。

### 識別の指針

- **原則**：修飾語は単数形（`tool calls`、× tools calls）
- **例外を疑うべき手がかり**：①man/woman である ②その語が本来複数形でしか使わない（arms, savings, sports, games）③「複数のものを集めた」という集合的意味が強い

## §3.83 物質名詞を使うか、-y / -en 形容詞を使うか

### 規則

品質名詞に `-y` や `-en` の付いた形容詞がある場合、どちらを使うかは——

- **事実（材料そのもの）に重点** → **名詞**を使う
- **描写・比喩に重点** → **-y / -en 形容詞**を使う

### 対比表

| 名詞（材料の事実） | 形容詞（描写・比喩） |
|---|---|
| `silk stockings`（絹の靴下） | `silky hair`（絹のようにしなやかな髪） |
| `a gold watch`（金時計） | `a golden opportunity`（絶好の機会） |
| `a stone wall`（石の塀） | `a stony road`（石ころだらけの道路）／`a stony heart`（＝hard。冷酷な心） |
| `lead pipes`（鉛管） | `a leaden sky`（＝heavy。どんよりした空） |
| `brass buttons`（真ちゅうのボタン） | `brazen impudence`（鉄面皮なあつかましさ） |
| — | `a wooden leg`（木製の脚/義足） |
| — | `woollen stockings`（毛の靴下） |

### ⚠️ 注意：wooden / woollen は比喩に使わない

`-y` / `-en` 形容詞はしばしば比喩的に用いられるが、**wooden と woollen は比喩用法を持たない**。

### ⚠️ wood と wooden の使い分け（頻出の混同）

| 表現 | 意味 |
|---|---|
| `a wood fire` | 薪を燃やす炉（**× a wooden fire とは決して言わない**） |
| `a wooden box` | 木箱（木で作られた箱） |
| `a wood box` | 薪入れ（薪を入れておく箱） |

**`wooden` は「木で作られた」、`wood` は「木材に関する・木材用の」。**

## §3.84 分詞形容詞（participial adjective）

### 規則

形容詞的修飾語として用いられる**分詞**は、形容詞の機能をもち、**分詞形容詞（participial adjective）**と呼ばれる。

### 判別基準（最重要）

**完全に形容詞の機能をもつと、副詞によって修飾されることもある。** これが「分詞が形容詞化しているか」を見分ける手がかりになる。

原典が挙げる証拠：

- `This book is not **very** interesting.`（副詞 very で修飾できる）
- `Can you find me a **more** interesting book?`（比較級を作れる）
- `Mary is **more** charming than her sister.`（比較級）
- `**How** charming she is!`（感嘆文で使える）
- `He is the **most** distinguished chemist in the country.`（最上級）
- `She had a **rather** pleased look.`（副詞 rather で修飾）

### 例

**現在分詞**：`running water`（流れ水/水道）／`a sleeping child`（眠っている子供）／`interesting`（興味深い）／`charming`（愛らしい）

**過去分詞**：`distinguished`（著名な）／`pleased`（うれしそうな）

### 技術英語での実例（学習ログより）

| 語 | 分詞の種類 | 元の動詞 | 意味 |
|---|---|---|---|
| `event-driven` | 過去分詞 | drive | イベント駆動の |
| `request-driven` | 過去分詞 | drive | リクエスト駆動の |
| `user-defined` | 過去分詞 | define | ユーザーが定義した |
| `prompt-based` | 過去分詞 | base | プロンプトに基づいた |
| `agent-based` | 過去分詞 | base | エージェントに基づいた |
| `built-in` | 過去分詞 | build in | 組み込みの |
| `bundled` | 過去分詞 | bundle | 同梱の |
| `fixed` | 過去分詞 | fix | 固定された |
| `automated` | 過去分詞 | automate | 自動化された |
| `existing` | **現在分詞** | exist | 現に存在している |
| `longer-running` | **現在分詞＋比較級** | run | 実行時間のより長い |
| `matching` | **現在分詞** | match | 合致する |

### ★ IT 英語の二大複合形容詞

| 接尾要素 | 意味 | 例 |
|---|---|---|
| **`-driven`** | **何が起動の引き金か** | event-driven / request-driven / data-driven / test-driven / market-driven |
| **`-based`** | **何を土台にしているか** | prompt-based / agent-based / cloud-based / web-based / rule-based |

**この2つは混同しやすいが、問う内容が違う。** `-driven` は「きっかけ」、`-based` は「基盤」。

## 型の判定に迷ったときの指針

英文解釈の【3. 英語の型と語法】を書く際、次の順で判定する。

1. **定形動詞を含む構造か** → VP1〜VP25（`hornby-patterns.md`）
2. **名詞が前置詞や節を伴って意味を完成させるか** → NP1〜NP3（`hornby-patterns.md`）
3. **形容詞が to不定詞・前置詞・節を後続要素として取るか** → AP1〜AP3（`hornby-patterns.md`）
4. **名詞が名詞を修飾しているか** → **§3.81・§3.82**（本ファイル）。**VP/NP/AP には該当しない**
5. **分詞が形容詞として働いているか** → **§3.84**（本ファイル）。**VP/NP/AP には該当しない**

**4・5 に該当する場合、「AP に該当なし」と書いたうえで、§番号を添えて語法メモに記録する。** 「型の枠外」で済ませず、原典のどこで扱われるかを示すこと。
