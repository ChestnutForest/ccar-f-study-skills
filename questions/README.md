# 想定問題アーカイブ

english-parsing の【10. 想定問題】で生成した CCAR-F 形式の4択問題を、1問1ファイルで蓄積している。

## 使い方

**解き直すとき** — ファイルを開くと、Scenario・Question・Options が英語で並んでいる。解答は `<details>` で折りたたまれているので、**選択肢まで読んで自分で選んでから**「正解と解説を開く」をクリックする。

**復習するとき** — 解答の下に、出題文そのものの解説（スラッシュリーディング・英語の型と語法・語彙メモ・全訳）がある。技術的な判断だけでなく、試験特有の英語表現も同時に確認できる。

**偏りを見るとき** — 下の一覧表で、判断軸とドメインの分布を把握する。特定の軸ばかりになっていたら、次の作問で意識的に変える。

## 判断の3軸

公式サンプル問題12問を分析すると、正解は次の3軸のいずれかで決まる。作問時も必ずどれかを軸に据えている。

| 軸 | 問われ方 | 正解の方向 |
|---|---|---|
| **確実性** | 失敗が許されない場面での実装選択 | プログラム的強制（フック・前提条件ゲート）。プロンプトは確率的遵守なので不可 |
| **根本原因** | 症状が出ている系の、どこを直すか | 上流の設計。下流が正常に動いているなら下流を疑わない |
| **比例性** | 「最初の一手（first step）」として何をするか | 低コスト・高レバレッジな施策。過剰設計は誤答 |

## ファイル名の規則

`question-YYYY-MM-DD-NN.md`

日付は問題を生成した日（JST）。`NN` は同じ日の連番（`01` から）。

## 注意

これらは**公式問題ではなく、学習用に生成した想定問題**である。公式サンプル問題の判断軸と誤答の型を踏襲しているが、難易度や着眼点が本番と完全に一致する保証はない。公式の出題傾向は『Claude Certified Architect – Foundations Exam Guide』§9 Sample Questions を参照すること。
