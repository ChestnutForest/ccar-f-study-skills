# Q&A 形式の知識カード（CCAR-F 技術知識）

## Q. Agent Skills とは何か。中身は何から成り、いつ起動するか？

**A. Agent Skills は「Claude の機能を拡張するモジュール式の能力」であり、各スキルは指示・メタデータ・任意のリソース（スクリプト、テンプレート）をひとまとめにし、関連する場面で Claude が自動的に使う。**

Agent Skills は modular capabilities（モジュール式の能力）で、Claude に後付けできる独立した機能単位である。各スキルは (a) 指示（instructions）、(b) メタデータ（metadata＝いつ使うかの判断材料。SKILL.md の description に相当）、(c) 任意のリソース（scripts / templates）をパッケージ化し、関連する場面でモデル側が自動的に呼び出す。普段は description（メタデータ）だけを見て、必要時に本文・リソースを読む「段階的開示」の設計と一致する。CCAR-F の Domain 3（Claude Code Configuration & Workflows）3.2（スキルの作成・設定）の前提知識にあたる。

（出典: Claude Platform Docs「Agent Skills overview」／学習日 2026-07-31）

## Q. Claude Code の Plugin（プラグイン）とは何か。何を同梱でき、何のために使うか？

**A. プラグインは、skills・agents・hooks・MCP servers という4種の拡張を1つにまとめて配れる「容器」であり、作った機能をプロジェクトやチームをまたいで共有するために使う。**

Plugins let you extend Claude Code with custom functionality that can be shared across projects and teams。プラグインは単体機能ではなく、スキル（定型能力）・カスタムエージェント・フック（ライフサイクル介入）・MCP サーバー（外部ツール接続）を束ねて配布できる。主眼は「作った拡張をプロジェクト・チーム横断で共有する」こと。ドキュメントは「使う人（Discover and install plugins）」「作る人（本ガイド）」「厳密な仕様（Plugins reference）」を目的別に分けて導線を切っている。CCAR-F では Domain 3（3.2）が主で、同梱する agents/hooks は Domain 1、MCP servers は Domain 2 にも接続する。「複数の拡張をチームへ一括配布するには何を使うか→プラグイン」という手段選択で問われうる。

（出典: Claude Code Docs「Create plugins」／学習日 2026-07-31）

## Q. ZDR（Zero Data Retention）とは何か。対象・機能ごとの適用・例外を説明せよ。

**A. ZDR は「API のレスポンス返却後、顧客データを保存しない」という組織単位の契約。ただしステートフルな機能・法令や安全性フラグ・Covered Models は対象外という穴がある。**

- **定義**：ZDR のもとでは、API レスポンス返却後に顧客データは保存（at rest）されない（法令順守・不正対策に必要な場合を除く）。非 ZDR では標準30日保持後に自動削除。
- **対象**：対象 API、商用組織キー経由の Anthropic 製品（API 経由の Claude Code を含む）、Claude for Enterprise の Claude Code。適用は組織単位で、セルフサービスのトグルではなくアカウントチーム経由。
- **機能ごとの適用（Agent Skills の英文が参照していた核心）**：保存が不要な機能（Messages API 等）は ZDR 対象。保存が必然のステートフル機能（バッチ処理・Files API・Managed Agents 等）は対象外。ZDR でも API は機能をブロックせず、そうした機能を使うことは「そのデータについてだけ ZDR の外に出る」選択で、その機能自身の保持ポリシーが適用される。ゆえに Agent Skills のような機能は「API and data retention」ページの機能適格性テーブルで個別確認が要る。
- **例外**：法令要求や trust & safety のフラグ時は保持されうる（Claude Code ではフラグ時最長2年）。
- **Covered Models**：Claude Fable 5 / Claude Mythos 5 は30日保持必須で ZDR 対象外。組織は特定ワークスペースだけ30日保持にしてこれらを使い、他は ZDR 維持が可能。

CCAR-F では Domain 5（Context Management & Reliability）やエンタープライズ運用・ガバナンスの観点に接続する。

（出典: Web 検索で確認した Claude Platform Docs「API and data retention」／Claude Code Docs「Zero data retention」／Anthropic プライバシーセンター／学習日 2026-07-31）

## 今日の型に関する気づき

**VP6A（他動詞＋名詞）と VP6C（他動詞＋動名詞）の対比**：`Create plugins`（VP6A・目的語は名詞）に対し、`covers creating your own plugins`（VP6C・目的語は動名詞）。cover は動名詞を目的語に取る。目的語が名詞か動名詞かで枝番が分かれる点を、同じ英文内で対比できた。

**VP18B（使役 let＋原形）**：`Plugins let you extend Claude Code`。let の後は to なしの原形。07-28 の Hooks（`Hooks let you run code`）と同型で、Anthropic ドキュメントに頻出の「機能が主語＋let＋人＋原形」パターン。

**VP14（extend A with B）**：`extend Claude Code with skills, agents, hooks, and MCP servers`。「A を B で拡張する」。前置詞は with。
